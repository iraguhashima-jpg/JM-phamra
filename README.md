# JM Pharma

JM Pharma is intended to be a pharmacy and patient medication collaboration platform. It is not yet implemented. This repository is currently an empty starting point; consult [`docs/PROGRESS.md`](docs/PROGRESS.md) before treating any capability as available.

## Status

No application runtime, migrations, authentication, user interface, integrations, or automated tests have been implemented or verified. Do not use this repository to manage real patient data.

## Project documents

- [Progress and milestone checklist](docs/PROGRESS.md)
- [Architecture decisions and security boundaries](docs/ARCHITECTURE.md)

## Intended technology

The requested target is Laravel, Vue 3, TypeScript, Inertia, and a relational database. Before choosing package versions or generating application code, inspect the supported PHP/Laravel versions and install dependencies in an environment where migrations, builds, and tests can be run. Do not treat this repository's empty state as evidence that any requested feature works.
